# ADR 001: Flutter로 4개 OS 지원

상태: 확정 · 날짜: 2026-11-03

## 배경

Windows, macOS, iOS, Android를 지원해야 하고, 적은 인원으로 구현과 유지보수를 감당해야 합니다.

## 결정

Flutter(Dart) 코드 하나로 4개 OS를 지원합니다. OS별 기능은 `lib/platform/`에 모읍니다.

## 결과

- OS별 UI를 따로 만들지 않아 구현과 유지보수 범위가 작습니다.
- 휴지통 이동처럼 OS 고유 기능에는 소량의 네이티브 코드가 필요할 수 있습니다.
- 다른 스택으로 옮기려면 앱을 사실상 다시 작성해야 합니다. M0 기술 검증이 실패하면 이 결정을 다시 판단합니다.
